B.Tech / Final Year Machine Learning Project

Bank Customer Data Analysis & Personal Loan Prediction using Machine Learning

A full-stack banking intelligence portal designed to analyze customer financial demographics, train multiple machine learning classification algorithms, compare performance metrics, and predict personal loan acceptance probability in real time.

Project Objective & Problem Statement

Problem Statement: Universal Bank is a growing commercial bank seeking to expand its asset customer base. Last year, the bank conducted a campaign that resulted in a ~10-17% acceptance rate for personal loans. Operating direct marketing campaigns is expensive; therefore, the bank wants to build a predictive machine learning system to identify prospective customers who have the highest probability of accepting a personal loan offer.

Primary Objective: Build an end-to-end Machine Learning web application that automates data cleaning, performs exploratory data analysis (EDA), trains multiple classification algorithms (Logistic Regression, Decision Tree, Random Forest, KNN), compares model metrics (Accuracy, Precision, Recall, F1), saves the top model, and serves live predictions through a web UI.

Kaggle Dataset Information

Dataset Source: Universal Bank Personal Loan Modelling Dataset (Kaggle)

Records: 5,000 Banking Customers | Features: 14 Demographic & Financial Variables

  • ID & ZIP Code: Identifier columns (dropped during ML preprocessing).
  • Age & Experience: Customer age (23-67 yrs) and work experience (0-43 yrs).
  • Income: Annual household income in $000s (range: $8k - $224k).
  • Family: Family size (1 to 4 persons).
  • CCAvg: Average monthly credit card spending in $000s.
  • Education: Level 1 (Undergraduate), Level 2 (Graduate), Level 3 (Advanced/Professional).
  • Mortgage: Value of house mortgage in $000s.
  • Securities, CD Account, Online, CreditCard: Binary indicators (0: No, 1: Yes).
  • Personal Loan (Target): Did customer accept personal loan offer? (0/1).

Machine Learning Workflow

1 Data Ingestion & Cleaning: Deduplication, missing value checks, and feature selection (dropping ID & ZIP Code).
2 Feature Scaling: StandardScaler transformation for parametric & distance models.
3 Train/Test Split: 80/20 stratified split (4,000 train records / 1,000 test records).
4 Algorithm Training: Logistic Regression, Decision Tree, Random Forest, K-Nearest Neighbors (KNN).
5 Performance Matrix: Evaluating Accuracy, Precision, Recall, F1 Score, and Confusion Matrix.
6 Model Serialization: Saving best performing model (`best_model.pkl`) using Joblib for real-time Flask API predictions.
