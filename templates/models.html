About Random Forest

1 Bootstrap Sampling: 100 decision trees are built, each on a random 63% sample (with replacement) of the training data using NumPy's random state.
2 Feature Randomness: At every node split, only a random subset of √11 ≈ 3 features are considered, reducing tree correlation.
3 Majority Voting: Each tree casts a vote (Accept / Reject). The final prediction is the class receiving the most votes across all 100 trees.
4 Feature Importance: Calculated using Gini Impurity decrease averaged across all trees — Income (46%) and CCAvg (31%) dominate.
